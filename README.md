## About

This repository tracks my daily coding practice: Skillii assignments, VAC coding questions, and LeetCode preparation. The goal is to build problem-solving skills step by step — understand the approach, dry-run the code, learn from mistakes, and revisit questions instead of copying solutions.

**Skillii instructors:** Prathmesh Sir and Anis Sir.

## How to Use

- Work topic by topic, in order. Try each problem independently before opening hints.
- Prefer **Java** for DSA; use Python only when a course assignment requires it.
- Mark a question **Completed** only when you can explain the logic and reproduce the solution.
- If hints were needed, re-solve later before marking it mastered.

## Problem-Solving Workflow

1. Restate the problem in simple words.
2. Identify inputs, outputs, constraints, and edge cases.
3. Start with brute force.
4. Dry-run on a small example.
5. Code it; test normal and edge cases.
6. Analyse time and space complexity.
7. If help was needed, close the solution and re-implement it.
8. Revisit hard problems after 1 day, 1 week, and 1 month.

## Long-Term Goals

- Strengthen fundamentals and arrays before advanced topics.
- Learn the core patterns: two pointers, sliding window, prefix sums, hashing, binary search, monotonic stack, BFS/DFS, greedy, DP.
- Practise trees, graphs, heaps, tries, and advanced structures once fundamentals are stable.
- Build consistency, accuracy, and independent problem-solving.

> **Consistency over speed. Understanding over copying. Progress over perfection.**
